# Terra de Gor

Jogo de ação co-op em 3D, inspirado em Drakantos, feito com **Three.js**.

## Rodar
```bash
npm install
npm run dev
```
Abra o endereço que aparecer no terminal (ex.: http://localhost:5173).

## Controles
- **WASD:** mover
- **Mouse:** mirar
- **Clique:** atacar
- **Espaço:** esquivar

## Estrutura
- `src/`: código do jogo (`main.js` é a cena, `hero.js` o herói, `input.js` os controles)
- `docs/GDD.md`: documento de design
- `docs/concept-art/`: concept arts dos heróis e das facções
- `public/models/`: modelos 3D `.glb` (em breve)
